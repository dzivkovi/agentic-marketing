# research/

Dated evidence, not the method. The method is [../MARKETING-ANATOMY.md](../MARKETING-ANATOMY.md).

Everything here is a snapshot of how an assessment was made on a given day: a tool reviewed, a vendor landscape mapped, a practitioner corpus read against the eight verbs. Tools and vendors change monthly, so a file here is correct as of its date and is not maintained as a buying guide. When a tool matters to you, run the [20-minute review procedure](../specs/tool-review.md) on it rather than trusting a snapshot.
